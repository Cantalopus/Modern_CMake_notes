# CLion, First Steps..
CLion is a paid, cross-platform IDE available for Windows, macOS, and Linux, developed by JetBrains. 

- CLion is a fully featured IDE.  
  
After downloading CLion from the official website (https://www.jetbrains.com/clion), you
can proceed with the usual installation process on the platform you’re using. CLion comes with
an adequate visual installer on Windows
