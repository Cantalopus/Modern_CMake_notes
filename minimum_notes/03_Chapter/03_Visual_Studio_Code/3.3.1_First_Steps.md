# First Steps with VS Code... 

VS Code is favored for its vast extension ecosystem and support for hundreds of programming languages (an estimated are over 220 different languages!).  
  
VSC is available from the official website: https://code.visualstudio.com/.  
  
• C/C++ by Microsoft
• C/C++ Extension Pack by Microsoft
• CMake by twxs
• CMake Tools by Microsoft  
  
I also suggest installing the Remote – SSH by Microsoft extension if you’re involved with remote projects, as this will make the experience much more coherent and comfortable; this extension not only takes care of file synchronization but will also enable you to remotely debug by attaching
to the debugger on the remote machine.
